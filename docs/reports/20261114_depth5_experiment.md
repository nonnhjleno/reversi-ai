# 深度5・7秒独立実験

## 目的と分岐点

Phase 6へ進まず、最大深度4（A0）と5（A1）を同じ7秒応答方針で比べる。開始時のorigin/mainは `43f636e6ad8ab5a146faf9a96ec3a49c5dfd227c`。Python互換性修正は含まれる。名前取得後EOF修正は含まれないため、`deef3fb`からソース・回帰テスト・修正記録だけを依存として取り込む。提出ZIP・manifestは取り込まない。

origin/mainには角接続辺石の10%評価候補（`98392b7`）が統合済みである。候補を比較へ混ぜないため、AI評価とそれを前提にした回帰を実験ブランチ上で変更前の形へ戻し、以前の評価・重みをA0/A1共通で使う。候補の既存報告・原証拠・固定baselineは保持する。この共通条件変更は深度差と分けて記録する。

## 実装前の設計

変更責務は時間対応反復深化の上限だけとする。実験用 `ResponsePolicy` と通常応答設定で深度5を切り替えられるよう上限定数を5へ広げ、既定設定値・提出ZIPは4のままにする。固定深度API・参照Minimax・評価関数・位置表・重み・手順・同点規則・時間の開始/停止/予約値は変更しない。深度6以上は拒否する。

深度5設定は実験用コピーの `response_config.json` でのみ有効にし、tracked defaultと既存ZIPを変えない。完全に終了したroot反復だけを採用し、中断深度を捨て、深度1未完了時は従来の合法フォールバックを返す。パスではplacement plyを減らさず、双方合法手なしを終局とする。

テストは、深度1〜4の独立参照との厳密一致、深度5の独立Minimax照合、同点・黒白・パス・終局・期限境界・中断・盤面/RNG/標準出力不変・1回適用・stdin/GUI互換性を対象とする。深度5を固定depth APIへ導入しない。現行Phase 4固定深度契約は1〜4、trace4の正式validatorも最大4のため、深度5結果は正式資格の対象外とし、validator・品質基準・trace契約は緩和しない。深度5は独立した生計測・参考評価として明示する。

## 比較計画と採否

A0=最大深度4、A1=最大深度5。両側とも従来評価、ordered Alpha-Beta、同じ配置・時間方針（全応答目標7秒、新反復開始期限6秒、停止要求6.5秒、後処理予約0.5秒）を使う。相手は相互の直接対局、固定search_v1、positional_v1、開発用仮想敵に限定する。開始前に局面母集団・seed・先後・局数と集計を固定し、2局smokeと少数開発対局後に本比較数を決める。held-outは候補選択に使わない。相手の内部予算がunknownならequal-workを主張しない。

採否は品質・合法性・応答安全性を必須とし、同一外部時間条件で勝率・勝ち点率・対応差を時間/メモリと併せて判断する。7秒超過・8秒超過・10秒超過、不正手・異常終了を別集計する。改善が明確でなければ保留、悪化なら不採用とし、自動で提出版へ採用しない。深度5完了率と平均・中央値・p95・p99・最大応答時間を報告し、両側が深度4までしか完了しない対局はそのまま明記する。
