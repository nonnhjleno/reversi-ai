## 実装と再現

`reversi.py` から `search_trace.py` と `timed_search.py` へモデルを渡す。既存の終局処理を優先し、非終局の葉は葉の手番でn-tupleを評価して根が白の場合だけ符号を反転する。根の行優先同点規則、着手数での深さ、パス処理、完了した反復と合法な代替手の規則を維持した。モデル指定がある場合は起動時に照合する。失敗時はプロセスがエラーで終了する。trace4とschema 5でモデルのID・実ファイル・起動読込区間を照合した。[接続とPowerShellの操作](../phase8_search_integration.md)

Phase 6の2-tuple 32種・3-tuple 24種、D4共有、手番別1,872重み、448参照と `V(s) = tanh(f(s))` をそのまま使った。参照の重複もPhase 6と同じ。次世代の予想石差モデルを接続する際は、教師と出力の意味を文書化し、非終局値を黒視点と葉評価の範囲へ変換する規約を別途検証する。

### 判定

現行の手作業評価を維持し、今回の6モデルを正式採用しない。独立評価へ進む開発基準を満たす系列はなかった。 開発基準は同一時間で系列平均55%以上、2 seed以上が50%超、予算・通信・合法性・モデル読込の異常0件。Zero-TDは3 seedとも50%を超え、系列平均が基準に1.53ポイント届かなかった。Pretrained-TDで50%を超えたのは702のみだった。

- Zero-TDは提出採用は保留。開発基準に届かず、独立評価へ進める根拠が不足している。
- Pretrained-TDは提出採用は保留。開発基準に届かず、独立評価へ進める根拠が不足している。

同一時間・最大深度4の成績で採否を判断し、固定深度2で確認された改善は探索深度と負荷の異なる比較結果として保持する。大学サーバーへの提出環境適合と独立序盤での優越性は未確認。
