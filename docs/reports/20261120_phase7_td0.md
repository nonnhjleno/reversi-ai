# Ranger Phase 7の実装・比較報告

Phase 6.5統合済みの `81b7b34` から開始し、両初期化を共通条件で各seed 10,000局まで学習した。G0 PASS、G1 PASS、G2 PASS、G3 PASS、G4 PASS、G5 PASS。[実験設計と再現手順](../phase7_design.md)

## 更新と独立検証

`phase7_td.py` が盤面・手番と1手方策、半勾配TD(0)、独立referee照合を持つ。`phase7_train.py` は学習の状態と局境界checkpoint、`phase7_eval.py` は既存Phase 6の凍結1手選択による独立対局、`phase7_results.py` は同じペアでの比較と棋譜の重複監査を担当する。

割引率1、途中報酬0、終局報酬は黒勝ち+1、白勝ち−1、引き分け0。次状態のブートストラップ値と現在状態の値は同じ更新前重みで求める。現在状態の重複参照数を使い、`θᵢ ← θᵢ + αδ(1−V²)cᵢ` を1回適用する。パスは盤面を保って手番だけを変え、終局直前の遷移を含める。Phase 6の1,872重み・448参照をそのまま使う。学習率は小さい候補で比較し、更新を参照数で割らない。

43件の新規テストで独立特徴、手計算、有限差分、黒白の更新、通常着手、両色の強制パス、満盤・空き付き終局、勝ち・負け・引き分けを照合した。両初期モデルのsmokeで4局連続実行と2局＋別プロセス2局を比べ、棋譜、モデルファイル、モデルID、乱数状態、累積件数が一致した。欠落、破損、設定不一致、出力重複を拒否した。関連回帰は195件をJUnitに保存した。

実験初回の自己対戦起動はログにディレクトリを渡して子プロセス起動前に失敗した。明示ログパスの別出力で再取得した。固定positionalのsmokeでは既存の `frozen_copy` manifest形式を読み違えた。両固定相手の形式を検査するように修正し、回帰テストと再実行で確認した。失敗のログと終了値は維持した。

主比較は1,200局・600先後ペア。合法性、パス・終局、異常なしの終了を全件で照合した。時間切れ、不正手、モデル読込失敗、fallbackは各0件。候補側の通常着手応答は全比較で最大20.4 ms、初回nameは最大0.404秒だった。先後別勝敗・石差・応答時間・各ペアの得点・通信記録は原証拠を参照する。区間は学習seedを固定した開発序盤の再標本化であり、seed間分散は別記した。

評価とD4同値の完全棋譜は0局。D4同値の先頭8配置までを通過した学習棋譜は8局だった。自己対戦は通常の初期盤面から始めて外部棋譜を投入しなかった。Phase 0 held-outとPhase 6.5の凍結testの結果は学習・調整・対局に使っていない。

**仮説A。** Zero-TDは10,000局で固定searchに対して全seedが学習前より高く、開発12ペアで +38.9pt（参考95%区間 +27.8〜+50.7pt）。固定positionalでは平均 +11.1ptで、区間はゼロをまたいだ。Pretrained-TDは固定positionalで全seedが初期値を上回り平均 +12.5pt、固定searchで +2.8ptだった。どちらの区間もゼロをまたいだ。10,000局の勝・敗・分は、Zero対positionalが28・42・2、Zero対searchが27・43・2、Pretrained対positionalが48・21・3、Pretrained対searchが33・35・4。

**仮説B。** 教師ありモデルは初期直接対局で22勝2敗、10,000局同士でも54勝16敗2分。事前学習系列は絶対成績の優位を保った。固定searchへのTDによる増分はZeroの方が36.1pt大きく、固定positionalでの増分差はPretrainedに +1.4ptだった。事前学習がTDの改善を速めたという証拠は得られなかった。Zero-TDの対searchは25.0〜62.5%と学習seed差が大きかった。いずれも開発条件の参考結果で、正式な棋力差の判定は保留する。

Phase 8の優先候補は固定searchへの成績が高かったPretrained-TD 5,000局の代表。Pretrained-TD 10,000局とZero-TD 10,000局の代表、Phase 6.5の凍結モデルも比較資産に残した。事前に決めたseed 701の代表を使い、評価後のseed選別はしなかった。
